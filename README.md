# 🐱 喵步星球 (MiaoBu Planet)

> 像猫一样探索未知目的地，提供有温度的旅行内容社区。

## 🌟 项目简介
喵步星球是一个基于 Django 开发的个人旅游网页。旨在打破传统社交平台的信息碎片化，为旅游博主和爱好者提供集游记展示、攻略查询、照片分享于一体的治愈系平台。

### 品牌理念
- **好奇**：像猫一样探索未知
- **温暖**：提供有温度的社区氛围
- **专业**：系统化的游记与攻略展示

## 🛠️ 技术栈
- **后端框架**：Django 4.2 (MTV架构)
- **前端框架**：Bootstrap 5 + 原生 JavaScript
- **数据库**：SQLite (开发环境) / MySQL (生产环境)
- **其他**：FontAwesome (图标库)
